# Мобильные исправления и QA — 16 ноября 2026

Статус обновлён: браузерный QA выполнен с разрешения пользователя в Chromium 138 и WebKit 27.2. Итоги, скриншоты и ограничения — в [browser-qa-2026-11-16/report.md](browser-qa-2026-11-16/report.md). Ниже сохранён первоначальный технический этап; таблица «оставшегося браузерного QA» описывает его состояние до браузерного прогона.

## Исправлено

- Раннер: два близких тапа — немедленный прыжок; свайп вверх тоже прыжок. Один тап меняет облик через 200 мс, необходимые для различения жестов. Мышь не затронута. Отложенный тап отменяется при отмене жеста, потере фокуса и сбросе партии.
- «Три дара»: жесты внутри трёх квестов не должны прокручивать родительскую страницу. Добавлены touch-action/overscroll containment, обработка pointercancel и предотвращение touchmove именно в игровых квестах.
- Монета получила красный контур по силуэту. Осколки собираются по расширенной области, даже если альфа-маска ещё не декодировалась. Для осколков 5/6 допуск больше; сборка зеркала на touch получила больший допуск прилипания.
- Видео Амипат: muted/playsinline, запуск после готовности данных, кнопка ручного запуска при запрете autoplay. Новый fast-start MP4 содержит прежний медиапоток без перекодирования: mdat побайтово одинаков. Метаданные moov находятся перед медиаданными.
- «Да»/«Нет»: непрозрачные подложки, контрастный текст и зона не менее 44 px. «Пройти ещё раз» увеличена и опущена.
- Финал «Трёх даров»: скрытые кнопки выключены. Чтение доступно после появления текста/кнопок и ожидания изображений (ограничено 8 сек); клик от жеста, начавшегося раньше, отклоняется. Требуется отдельное свежее нажатие.
- Все три игры: загрузку в развёрнутом окне можно отменить крестиком сразу, без ожидания ready/таймаута. Страница разблокируется, поздние сообщения удалённого iframe игнорируются, повторный запуск создаёт новый iframe.

## Производительность без упрощения иллюстраций

- 14 значков карты заранее подготовлены из тех же листов с теми же цветовыми матрицами, без изменения размеров пикселей и с WebP lossless. В браузере больше не нужны большие цветовые SVG-фильтры для каждого маленького значка. Скрипт воспроизведения: scripts/prepare-map-markers.py. Исходные листы сохранены.
- Заливка региона сохраняет шум, смещение и мягкий фронт. Буфер фильтра и маски ограничен геометрией региона с запасом 32 единицы. После окончания маска снимается, чтобы фильтр не продолжал участвовать в перерисовке.
- Свитчер сохраняет прежнюю форму и morph. Только видимые экземпляры меняются покадрово; IntersectionObserver заменил чтение геометрии при клике. Повторный выбор текущего состояния не запускает новую анимацию. Быстрый обратный клик отменяет предыдущий RAF. Touch-action: manipulation исключает ожидание double-tap zoom на контроле.
- Уже загруженные статичные фигурки в музыкальных лентах сохраняют src при смене темы; повторная загрузка/декодирование не провоцируется удалением src.
- «Реки» не ждут document.fonts.ready всей страницы. Ожидание собственного шрифта ограничено 1200 мс, ошибка шрифта не обрывает модуль. После догрузки метрики пересчитываются.
- Контур стебля на hero не строится повторно при уведомлении ResizeObserver с той же геометрией.

Плавность/FPS после изменений ещё нужно измерить в браузере и на телефоне. Тесты ниже подтверждают поведение кода, а не субъективную плавность.

## Выполненные проверки

- 23 набора Node-проверок: запуск/пауза/выход/повтор, защита postMessage origin/source, управление и клавиши, столкновения, онбординг, прогресс, путник, шэринг, диплинки, 128 ветвей карточной игры, выбор истории, политика соединения.
- Новые проверки: test-runner-touch.mjs; test-gifts-final-gate.mjs; test-gifts-mobile.mjs; test-loading-cancel.mjs; test-map-motion.mjs.
- Карта: прерывание morph быстрым обратным кликом, отсутствие принудительного чтения layout внутри переключения, синхронизация невидимых свитчеров в конце, снятие маски завершённой заливки.
- 177 локальных ссылок HTML/CSS четырёх входных страниц и стилей: отсутствующих файлов не найдено.
- HTTP 200 с корректными MIME на 127.0.0.1:4173 и 192.168.0.18:4180: главная, voices.js, touch-input.js, final-actions.js, новый MP4 и новый значок карты.
- Синтаксис изменённых JS-файлов проверен Node. Это не проверка совместимости API браузеров.

## Матрица оставшегося браузерного QA

| Сценарий | Что проверить | Текущий статус |
|---|---|---|
| iPhone / Safari, портрет и горизонталь | safe areas, адресная строка, жесты, зеркальное видео, свитчеры | Нужен браузер/устройство |
| Android / Chrome и Яндекс | drag/drop, быстрые тапы, свайпы, fullscreen, возврат из книги | Нужен браузер/устройство |
| Telegram WebView на iOS/Android | запуск из сообщения, закрытие, звук после жеста, шэринг | Нужен Telegram на устройстве |
| Telegram превью ссылки | OG title/description добавлены; картинку и og:url привязать к публичному HTTPS-адресу | Локальный Wi-Fi адрес недоступен crawler Telegram; не опубликовано |
| Slow 3G, потеря связи во время загрузки | таймаут, отмена загрузки, повтор после восстановления, отсутствие утечки iframe | Логика таймаута/отмены проверена; сетевой browser test ожидается |
| Запрет аналитики | недоступность mc.yandex.ru не блокирует локальный интерфейс | Аналитика async и не awaited; браузерная блокировка ещё не воспроизведена |
| Экономия трафика / offline / reduced motion | корректный старт и остановка декоративной анимации | Политика проверена VM-тестами, на устройствах не проверена |
| VPN / «белые списки» оператора | доступность самого домена, редиректов onelink, Telegram, внешнего альбома | Нужны конкретная сеть и публичный URL; эмуляция не доказывает доступность |

Основные игровые скрипты, шрифты и изображения раздаются локально. Переходы на книги, Telegram и альбом — внешние ссылки; локальная оптимизация не может обеспечить их доступность при блокировке домена оператором. Сообщение об отключении VPN носит информационный характер, VPN не определяется автоматически.

Проверка с телефона в одной Wi-Fi сети: http://192.168.0.18:4180/. Для проверки мобильного оператора нужен опубликованный HTTPS-адрес, которого в этой задаче не создавали.
