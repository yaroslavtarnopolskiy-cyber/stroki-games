# Медленное соединение и выход из первой игры

- В runner первый крестик открывает результат, следующий сворачивает игру на сайте и ставит её на паузу.
- connection-policy.js откладывает декоративную анимацию до события load и отключает её при offline, saveData, 2G/3G, downlink ниже 1.5 Mbps или RTT выше 600 ms. Изменения online/offline/connection учитываются автоматически. Предпочтение reduced motion сохраняется.
- Без Network Information API сайт не делает предположений о скорости: действует ожидание load, offline и reduced motion. Дополнительных скачиваний для замера скорости нет.
- Свитчеры и переходы при ограничении работают без плавной анимации. Реки сохраняют интерактивные слова и статичную композицию без постоянного requestAnimationFrame.
- Музыкальные полосы статичны; крупные фигурки используют статичные SVG. Анимированные варианты загружаются только после разрешения движения. Предзагрузка блока сокращена с 600 до 120 px до экрана.
- Обе игры по-прежнему создают iframe только после действия пользователя. Аудио hero сохраняет preload=none.
- Подсказка VPN показывается над навигацией hero один раз на браузер, если localStorage доступен.

Проверено автоматически: test-connection-policy, test-runner-finish, test-runner-keyboard, test-runner-result, test-gifts-host, test-deeplinks. Физическая проверка в браузере с сетевым throttling не проведена: инструмент управления браузером недоступен. Измеренного прироста скорости нет.

## Устранение задержанного старта анимаций
Начальный запрет движения больше не ждёт window.load (картинки, внешняя Метрика и другие ресурсы). Движение разрешается уже при interactive/DOMContentLoaded. Событие load оставлено только как повторная синхронизация. Метка effectiveType=3g без плохих downlink/RTT больше не блокирует движение: начальная оценка браузера может быть неточной. Offline, saveData, slow-2g/2g, фактически низкая downlink, высокий RTT и reduced motion учитываются по-прежнему. VPN-подсказка также запускается от DOMContentLoaded. Проверены сценарии DOM без load и быстрый канал с меткой 3g.

## Окончательное упрощение блокировки движения
Декоративное движение больше не ждёт load или DOMContentLoaded. Localhost/127.0.0.1/IPv6 loopback не блокируется из-за navigator.onLine, effectiveType, RTT или downlink. На других адресах учитываются offline и явно 2G, но не колеблющиеся оценки RTT/downlink. SaveData и prefers-reduced-motion учитываются везде. Из CSS удалён глобальный animation-play-state:paused для всех элементов; статический режим ограничен музыкальными декоративными анимациями и переходами свитчеров. Это исключает остановку всей страницы из-за одной оценки соединения. Пауза вне экрана и при скрытии вкладки в отдельных блоках сохранена.
Проверены localhost с offline/2G/high RTT/low downlink, экономия трафика и reduced motion. Воспроизведение в реальном браузере не проверено: браузерный инструмент недоступен.
