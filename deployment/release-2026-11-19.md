# Обновление 19 ноября 2026

Готовая веб-версия находится в `dist/`. Пакеты для ручной загрузки в S3 воспроизводятся командой:

```bash
python3 scripts/package-s3.py --output output/releases/2026-11-19-rc2
```

В каждом архиве 630 файлов; верхний уровень — папка `pesni-zemli`, внутри неё `index.html`. ZIP нужно распаковать до загрузки в S3. Для RC используйте `pesni-zemli-rc.zip`, для PROD — отдельный `pesni-zemli-prod.zip` после согласования RC.

В обновление включены кликабельные области земель, сдвиг подписи Подмосковья, согласованный монохромный италмас с прозрачным фоном, более отзывчивый и высокий прыжок раннера, увеличенные подсказки заданий «Трёх даров» с компактной светлой подложкой и уточнёнными инструкциями полива.

Проверки: все 26 регрессионных наборов прошли. Локально в Chromium проверены подсказки на горизонтальном экране 852×393 и новый значок карты. Загрузку в S3 это обновление не выполняет.

Подробная инструкция: [RC-PROD.md](RC-PROD.md).
