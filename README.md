# Песни Земли

Интерактивный лендинг КИОН Строки: семь земель и рассказов, режимы «Жизнь» / «Смерть», реки слов, подбор истории, музыкальный альбом, Telegram-бот и статьи. Первая игра — раннер по мотивам «Маски человека» — встроена в главный игровой блок; два следующих игровых места пока содержат превью.

## Локальный запуск

Требуется Python 3. Сборка и установка зависимостей не нужны.

```bash
python3 -m http.server 4173 --directory dist
```

Открыть [http://127.0.0.1:4173/](http://127.0.0.1:4173/). Для проверки телефона нужен доступный ему адрес компьютера в той же сети.

## Структура

- `dist/index.html` — страница лендинга.
- `dist/typography.css` — общие роли текста; подключается после стилей блоков.
- `dist/voices.js`, `voices.css`, `map-study/` — карта и карточки земель.
- `dist/word-stream/` — интерактивные реки слов.
- `dist/story-matcher/` — вопросы и карусель рассказов.
- `dist/games/runner/` — рабочая копия первой игры с адаптером к лендингу.
- `dist/games/runner-embed.js`, `runner-embed.css` — загрузка iframe, пауза и разворачивание.
- `dist/album-promo/` — музыкальный эпилог, ленты и сцена музыкантов.
- `dist/afterword/` — бот и карточки статей.
- `scripts/` — локальные проверки и вспомогательные скрипты.
- `reviews/runner-integration.md` — техническое ревью интеграции игры и оставшиеся проверки.

## Проверки

Нужен Node.js; внешние npm-пакеты для этих тестов не требуются.

```bash
node scripts/test-story-matcher.mjs
node scripts/test-runner-bridge.mjs
```

Первый тест проверяет матрицу 64 ответов, карусель и быстрые переключения. Второй — остановку игровых часов, кадров и таймеров, продолжение и проверку источника сообщений iframe.

## Первая игра

Игра загружается по нажатию на кнопку внутри фрейма. Десктоп: ЛКМ / пробел — прыжок, ПКМ / E — облик; также поддерживаются стрелки вверх / вниз. Телефон: тап — облик, свайп вверх — прыжок. Доступны пауза и разворачивание. В портретном развёрнутом режиме игровая область поворачивается горизонтально.

Код и графика исходного пакета находятся в `dist/games/runner/`; изменены точка подключения адаптера, выход/ссылки результата и сброс чекпоинта. Полное прохождение, длительный бесконечный режим и жесты на физических телефонах ещё требуют финального тестирования.

## Материалы

В репозитории сохранены рабочие визуалы и часть исходных вариантов. Для карт и иллюстраций лендинг использует облегчённые WebP с проверенным совпадением пикселей и прозрачности; PNG-оригиналы сохранены рядом. Служебные данные хостинга, ключи и локальные скриншоты в репозиторий не входят.
